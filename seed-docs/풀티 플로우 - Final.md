# 풀티 플로우 - Final

# A. 회원 / 권한 플로우

```
회원가입
→ 역할 선택
   - 일반 회원
   - 셀러 (개인 / 사업자)

일반 회원 가입
→ 이메일 가입 / 소셜 로그인
→ 이용 가능 기능
   - 상품 구매 / 렌탈
   - GET 요청 (구해주세요)
   - SELL 요청 (위탁 / 매입 신청) ← 직접 등록 아님, 풀티에 신청하는 것

셀러 가입
→ 이메일 가입 / 소셜 로그인
→ 셀러 유형 선택
   - 개인 셀러
   - 사업자 셀러
→ 필수 추가정보 입력 (소셜 로그인에도 해당)
→ 관리자 승인 심사
   - 심사 중 / 승인 완료 / 반려
→ 승인 완료 후 셀러 기능 활성화
   - 상품 등록 (**풀티 사전 검수 후 노출**)
   - 가격 입력 / GET (구해주세요) 응답
   - 렌탈 공급 설정
   - 정산 관리

예외
→ 셀러는 소셜 로그인 시에도 추가 필수정보 입력 필요
→ 모든 상품은 풀티 사전 검수 완료 후 노출
```

# C. 렌탈 플로우

```
상품 상세
→ 렌탈 기간 선택
	- 선택한 배송 시작일 기준으로 렌탈 기간 시작
→ 배송지 입력
→ 결제
→ 결제 완료
→ 배송 준비
→ 배송 완료
→ 렌탈 이용 중
→ 렌탈 종료 알림
	- 기본: 종료 7일 전 알림 발송 → 종료 72시간 전까지 선택
	- 렌탈 기간이 7일인 경우:
	  종료 3일 전 알림 → 종료 48시간 전까지 선택
	
	- 미선택 시: 
	→ 자동으로 회수 가능 상품 상태 전환
	→ 다른 사용자 구매 가능 상태로 자동 변경

렌탈 종료 시 분기
1) 연장 (연장 시 추가 최대 90일)
2) 구매 전환 → → 렌탈 시작 시점 판매가 - 누적 렌탈료 차액 결제 → 소유권 이전 → 가구 자산화 등록 가능
3) 회수
   → 직접 반납 / 풀티 픽업 선택
   → 회수 비용 결제
   → 회수 진행
   → 풀티 검수 및 등급 결정
   → 재판매 상품 자동 전환

렌탈료 계산 정책
- 최대 렌탈기간: 90일 (연장 포함)
- 7일까지: 판매가의 10% 고정
- 8일 이상: 구간별 일요율 적용
  · 8~14일: 판매가 × 0.0075 × 선택일수
  · 15~30일: 판매가 × 0.00609 × 선택일수
  · 31~60일: 판매가 × 0.0046 × 선택일수
  · 61~90일: 판매가 × 0.00307 × 선택일수
- 최종 금액 100원 단위 올림
- 연장 시 렌탈료 계산 기준 -> 위와 동일
```

# D. GET / SELL 플로우

```
GET과 SELL 모두 로그인 일반 유저에게만 가능

GET (구해주세요)
→ **챗봇 형식**으로 GET 요청 폼 작성
   - 브랜드 / 카테고리 / 상태 / 예산 등 순차 질문
   - 추가 알림 옵션 설정
   - 요청 조건과 일부 달라도 알림 수신 여부
     · 알림 받기
     · 알림 받지 않기
	 - 요청 유지 기간 설정
	   - 3개월 / 6개월 / 12개월
	   - 선택 기간 종료 시 알림 신청 자동 취소
	 - 완료 시 요청 등록
→ 마이페이지 GET 내역 저장
→ 관리자 및 셀러에게 폼 데이터로 전달
→ 셀러 제안 ("해당 상품 있음" + 상품/가격 제시)
→ 유저 확인
→ 거래 (구매 플로우로 연결)

SELL (매입 / 위탁)
→ 유저 매입 / 위탁 신청
→ 크기 / 지역 입력 → 기본 픽업 배송비 자동 산출
→ 추가 작업 가능성 체크 (조립·설치 등 현장 확인 후 별도 청구 안내)
→ 기본 픽업 배송비 결제 (확정)
→ 일정 조율
→ 픽업
→ (추가 작업 발생 시) 관리자 추가 결제 요청 발송 
→ 유저 확인 후 결제
	 - 미결제 시 2일 후 재알림
   - 3일 이상 미결제 시 → 상품 반송 처리
→ 검수 
   - 반려 시 → 제품 하자 또는 사진과 상이한 경우 저 통보 후 반송 처리 (판매자 배송비 부담)
   - 통과 시 → 최종 금액 제안
→ 최종 금액 제안 (매입가 / 위탁 조건)
→ 유저 수락 / 거절
   - 거절 시 (**사유 선택지: 가격(제안가가 너무 낮음), 기타(서술형)**) → 관리자 측에서 제안 줄 수 있게 (채널톡)
→ 계약서 작성
→ 매입 / 위탁 분기
	- 매입
		- 풀티 소유권 이전
		- 정산 완료
		- 상품 등록 및 판매

	- 위탁
		- 풀티 입점 처리
		- 판매 완료 시 수수료 차감 후 정산
```

# E. 유저 마이페이지 플로우

```jsx
**주문 조회**
→ 배송 전
   - 배송 조회
→ 배송 완료
   - 배송 완료 4일 후 자동 구매 확정
   - 취소는 배송 직전까지만 가능
~~~~   - 후기 작성 (리빙 라운지 페이지로 이동)
   - 배송 조회
→ 각 상품 주문 상세 보기
   - 주문 상품 내역
   - 결제 정보
   - 환불 정보 (취소)

→ 렌탈중인 상품
	- 상품 내역 (상품 이미지, 브랜드, 상품명, 렌탈 시작-종료 날짜, 렌탈가)
	- 상품 누르면 상세 보기
	  - 최초 렌탈 기간
	  - 연장 이력 (연장 1차)
	  - 현재 상태
	- 종료 7일 전: 다음 단계 선택 버튼 활성화
	   1) 연장 (드롭다운 날짜 선택 - 확인 필요)
	      - 연장 완료 시 연장 뱃지 표시
	      - 연장 이후에는 구매 전환 또는 회수만 가능
	   2) 구매 전환
	      - 판매가 - 렌탈료 납부 금액 = 차액 즉시 결제
	      - 소유권 이전
	      - 가구 자산화 등록 가능
	   3) 회수
	      - 풀티 픽업 수거 / 직접 반납 (선택)
			  - 수거 현황 표시

→ 취소 (반품) 내역
	- 취소 내역 보기
	- 반품 내역 보기
		- 반품 상세 보기
		- 주문 상세 보기 (주문 조회의 주문 상세 내역으로 연결)

**GET 내역**
→ 신청한 상품 내역
→ 상품 누르면 신청 폼 내역 확인
**→ 셀러 제안 알림
   - 제안 확인 (상품 / 상품 사진 / 사용 기간 / 가격)
   - 수락 / 거절
   - 수락 시 구매 플로우로 연결**

**SELL 내역**
→ 상품 이미지, 브랜드, 모델명, 옵션, 제품 상태(등급)
→ 연결된 GET 상품 (없으면 - 표시)
→ 진행 상황 status
   접수 완료 → 배송비 결제 완료 → 픽업 대기 → 픽업 완료
   → 검수 중 → 반려 / 최종 금액 제안 확인 대기
   → 계약 완료
→ 매입 / 위탁 계약서
→ 관리 (상세보기 버튼 → 신청 폼 내역 확인)

**COLLECTION**
→ 위시 리스트
	- 찜한 상품 내역 (상품 사진 UI)
	   - 품절 상품은 SOLD OUT 뱃지 표시

→ 자산 리포트 (일반 회원)  
	- 직접 **소유한** 가구 전체 표시 (등록 가능)
	   - 소유권 이전 시점에 가구별 고유 ID 자동 생성
	   - 중고 / 렌탈 / 판매 이력 (풀티에서 거래가 일어났을 경우에만) 추적 가능
  - 소유 가구를 팔 때 해당 등급 (등급별 현재 예상 가치 표시 (SS / S / A+ / A / B)일 경우에 따른 가격 표시 
	   - 온라인 최저가 기반 수식 기준 확인 필요
	- 보유 가구 개별 및 총 합산 가치 실시간 (하루 단위) 차트 시각화 
	- 자산 리포트 내 가구에 판매 버튼 누를 시 SELL 페이지 이동 
	
**리빙 라운지**
→ 리뷰 내역
   - 내가 작성한 리뷰 목록 (리뷰 누르면 수정 / 삭제)
→ 정보글 작성
   - 작성한 정보글 목록 (정보글 누르면 수정 / 삭제)

**계정설정**
→ 회원정보 수정
	- 계정 정보
	  - 아이디
	  - 비밀번호 (변경 버튼)
	- 배송지 목록
	- 회원탈퇴

**→ 알림 설정
	- 배송 상황 알림
	- 렌탈 종료 알림
	- GET 제안 알림
	- SELL 진행 상황 알림**

→ 나의 등급 / 쿠폰 / 풀티머니
	- 현재 등급 표시 (확인 필요 - 등급 기준 및 혜택)
	- 보유 쿠폰 목록 (확인 필요 - 쿠폰 발급 기준)
	- 풀티머니 보유 금액 표시
	- 적립 / 사용 이력
```

# F. 셀러 어드민페이지 플로우

```jsx
대시보드
→ 판매 중인 상품 수
→ 렌탈 중인 상품 수
→ 이번 달 예상 정산액
→ 전체 현황 요약 노출

상품 등록
→ 상품 등록 폼 작성
   - 브랜드 / 모델명 / 옵션 / 상태 / 이미지
   - 모델 선택 시 신품 최저가 자동 노출 (가이드 프라이싱)
   - 풀티 등급 선택 시 권장 판매가 가이드 제시
   - 가격 설정
     - 공급가 (직접 입력)
     - 판매가 (직접 입력)
       - S등급 입력가가 신품 최저가보다 높을 경우 등록 제한
     - 수수료 (풀티 어드민 설정값 n% 자동 입력 / 고정)
     - 배송비 (**풀티가 구매자에게 발송하는 배송비 - 확인 필요**)
     - VAT (직접 입력)
     - 실 정산액 자동 계산 및 표시
   - 렌탈 공급 여부 토글
     - 렌탈 ON 시 제공 가능한 최소 / 최대 일수 설정
     - 일수 입력하면 렌탈료 자동 산정
     - 예상 수익금 및 풀티 수수료 자동 표시
→ 등록 버튼 → 풀티 어드민에 신규 검수 요청 알림 발송
→ 풀티로 실물 배송 (셀러 부담)
→ 풀티 검수
   - 반려 시 → 사유 안내 후 반송
   - 승인 시 → 풀티 플랫폼에 상품 노출
→ 구매 발생 시 풀티가 구매자에게 발송 (일반 셀러) / 사업자 셀러는 직접 배송
→ **판매 중 상태 관리**

판매중 제품 관리

GET 알림 설정
→ 관심 브랜드 / 카테고리 설정
→ 관련 GET 요청 알림 수신
→ 제안 발송 **(상품 / 상품 사진 / 사용 기간 / 가격)**

정산 관리 
→ 정산 내역 조회
   - 판매 정산 / 렌탈 정산 구분 조회
   - 기간별 필터 (주간 / 월간 / 직접 설정)
→ 정산 상태
   - 정산 예정 / 정산 완료
→ 정산 상세
   - 상품명 / 판매가 / 수수료 n% / 실 정산액
   - 렌탈의 경우 렌탈 기간 및 렌탈료 표시
→ 정산 계좌 관리
   - 계좌 등록 / 수정
```

# G. 풀티 어드민 운영 플로우

```
대시보드
→ 신규 검수 요청 현황
→ 진행 중인 SELL 건수
→ 렌탈 중인 상품 현황
→ 이번 달 정산 예정액
→ 미처리 항목 알림 (검수 대기 / 계약 대기 / 반려 처리 등)

회원 관리
→ 일반 회원 조회 및 상태 관리 (회원 등급 필터)
→ 셀러 승인 심사 / 반려
   - 개인 셀러 / 사업자 셀러 구분 조회

상품 관리
→ 셀러 신규 검수 요청 조회
   - 승인 시 → 플랫폼 노출
   - 반려 시 → 사유 입력 및 셀러 통보 (수정 요청)
→ 풀티 자체 상품 등록 (= 상품 등록 플로우 in 셀러 어드민)
→ 구매 발생 시 **풀티가 구매자에게 발송 처리 (사업자만 직배송 가능)**
→ 판매 / 렌탈 상품 상태 관리

GET 관리
→ GET 요청 조회
→ 셀러 제안 현황 확인
→ 매칭 상태 관리

SELL 관리
→ 신청 접수 조회
→ 일정 조율
→ 픽업 배송비 결제 확인
→ 추가 작업 발생 시 추가 결제 요청 발송 **(거의 발생하지 않음)**
   - 미결제 시 N일 후 재알림 **(자동 결제 알아보기)**
   - N일 이상 미결제 시 반송 처리 (N일: 고객사 확인 필요)
→ 검수 결과 등록 및 유저 통보
   - 반려 시 반송 처리
   - 승인 시 최종 금액 제안 등록
→ 유저 수락 / 거절 확인
```
